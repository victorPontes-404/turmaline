What is Turmaline?

Turmaline is a high-fidelity visual orchestration engine designed to resolve the "invisibility of dependencies" in software architecture.

It implements a Neural Task Networking approach, treating every project component as a dynamic node.

Grounded in Cognitive Load Theory, the system maps project telemetry intelligently.

By providing multi-faceted views, it allows teams to navigate architectural layers without noise.

Features

Everything your team needs to build, document and ship.

⬡

Graph Map

Visualize dependencies between tasks, documents and components as an interactive node graph. Spot bottlenecks before they happen.

◈

Rich Text Editor

Write and organize project documentation in Markdown with a clean, distraction-free editor. Keep your knowledge base structured and searchable.

▦

Task Board

Manage sprints and track work with a Kanban board. Link tasks directly to documents and components so nothing gets lost.

⬡

Chromatic Engine

Monitor system and project health through thermal state transitions. Understand the status of every layer at a glance.

◈

Layer Isolation

Reduce cognitive load with progressive disclosure. Navigate architectural layers without noise, focusing on what matters now.

▦

Open Ecosystem

Expand Turmaline's functionality with modular plugins. Built to integrate with the tools your team already uses.
